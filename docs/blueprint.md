# **App Name**: BrainWave Blitz

## Core Features:

- AI Trivia Generation: Generate trivia questions on a range of topics using AI. This AI tool will be able to provide tailored learning or entertainment content across any user defined topics.
- Interactive Quiz UI: Present questions in a clear, engaging interface with multiple-choice answers.
- Real-time Scoring: Implement a scoring system with immediate feedback on answer accuracy.
- Category Selection: Allow users to select from different trivia categories.
- Progress Tracking: Display user progress visually through progress bars.
- Timed Rounds: Enable timed rounds to test user knowledge under pressure.

## Style Guidelines:

- Primary color: A vibrant blue (#42A5F5) to promote feelings of intellect and focus, avoiding the cliché of the color green being linked to 'go'.
- Background color: A desaturated light blue (#E3F2FD) that offers a clean and non-distracting backdrop.
- Accent color: A bright yellow (#FFEB3B), which stands out and offers excellent contrast without being too jarring.
- Body and headline font: 'PT Sans', a versatile and friendly sans-serif for clear readability.
- Use simple, geometric icons for categories and interactive elements.
- Subtle animations and transitions to enhance user interaction and provide feedback.
